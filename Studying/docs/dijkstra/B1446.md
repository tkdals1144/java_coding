## B1446 - 지름길

**알고리즘 :** dijkstra  
**언어 :** JAVA

### 문제 요약

dp로 풀면 쉬운 문제. 다익스트라 연습 겸 다익스트라로 풀어보았다

---

### 핵심 아이디어

- dp
- 다익스트라

---

### 문제 접근 방식

1. 종점의 번호와 가중치를 저장할 Node inner class 생성
2. 각 종점별로 최단 거리를 저장할 dist 1차원 배열 생성
3. PriorityQueue를 Node의 dist를 오름차순으로 생성
4. 종료지점이 0이고 현재 길이가 0인 노드를 pq에 저장
5. 입력에 따라 올바른 간선 생성 및 연결
6. pq에서 가중치인 dist 값 자체가 최단거리로 저장된 dist[now.number] 보다 크다면 continue
7. now가 가리키는 모든 노드를 확인하고 (다음 노드의 가중치 + 현재 노드의 길이) 가 최단거리 dist[next.number] 보다 작다면 간선 완화 진행
8. 간선 완화가 진행되었다면 새로운 노드를 pq에 삽입
9. 최종적으로 답을 출력
