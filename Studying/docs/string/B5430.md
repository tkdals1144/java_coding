---

### 문제 요약

신호에 따라 배열을 뒤집거나 끝 값을 제거하는 문제다  

---

### 핵심 아이디어

- deque

---

### 문제 접근 방식

1. 입력 신호를 char 배열에 저장
2. 값을 저장할 deque 생성
3. 쓸데없는 값을 제거하기 위해 replace와 StringTokenzier 사용
4. boolean check를 이용해 뒤집힘 여부 확인
5. 뒤집힘 상태에 따라 삽입, 삭제 연산 변경
6. 빈 배열을 빼려고 하면 error를 return
7. 최종적으로 출력
