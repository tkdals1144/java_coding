## B 11660 - 구간 합 구하기 5

**문제 링크 :** https://www.acmicpc.net/problem/11660  
**알고리즘 :** prefixSum  
**언어 :** JAVA  

[ 코드 보기 ](../../src/prefixSum/B11660.java)  

---

### 문제 요약

각 행별로 1차원 누적합을 저장하여 해결하는 문제다

---

### 핵심 아이디어

- Prefix Sum

---

### 문제 접근 방식

1. N줄만큼 입력받은 값을 2차원 dp배열에 각 행별로 누적합을 저장
2. M줄만큼 x1, x2, y1, y2 값을 입력
3. 각 입력값에 맞게 각 행별 누적합 값을 계산
4. 계산된 값들을 StringBuilder에 쌓음
5. 최종적으로 쌓인 값을 출력
