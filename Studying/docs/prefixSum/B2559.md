## B 2559 - 수열

**문제 링크 :** https://www.acmicpc.net/problem/2559  
**알고리즘 :** prefixSum  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B2559.java)  

---

### 문제 요약

주어진 수열을 누적합으로 비교하여 최대값을 출력하는 문제

---

### 핵심 아이디어

- Prefix Sum

---

### 문제 접근 방식

1. 전체 수열을 1차원 정적 배열에 삽입
2. max값과, temp값 초기화 작업 실행
3. 1중 반복문을 돌며 누적합을 temp에 저장하고 max값과 비교
4. 최종적으로 max 값 출력
