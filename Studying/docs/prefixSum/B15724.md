## B 15724 - 주지수

**문제 링크 :** https://www.acmicpc.net/problem/15724  
**알고리즘 :** prefixSum  
**언어 :** JAVA  

[ 코드 보기 ](../../src/prefixSum/B15724.java)  

---

### 문제 요약

주어진 값을 2차원 누적값으로 저장해서 필요한 값을 출력하는 문제

---

### 핵심 아이디어

- Prefix Sum
- 2차원 누적합

---

### 문제 접근 방식

1. 입력받은 값을 공간형태로 저장할 2차원 dp 선언
2. 입력값을 받으며 2중 for문을 돌려 입력값을 dp에 누적
3. 알맞게 누적된 값을 StringBuilder에 쌓음
4. 최종적으로 쌓은 값을 출력
