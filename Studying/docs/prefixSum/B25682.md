## B 25682 - 체스판 다시 칠하기 2

**문제 링크 :** https://www.acmicpc.net/problem/25682  
**알고리즘 :** prefixSum  
**언어 :** JAVA  

[ 코드 보기 ](../../src/prefixSum/B25682.java)  

---

### 문제 요약

첫 시작이 white, black 인 2차원 누적합 dp 배열을 만들어 해결하는 문제다

---

### 핵심 아이디어

- Prefix Sum
- 2차원 누적합

---

### 문제 접근 방식

1. whiteDp, blackDp 두개의 2차원 dp 배열을 1차원은 N+1, 2차원은 M+1 크기로 생성
2. 입력값을 비교 연산하여 공간값이 누적되도록 2개의 배열을 채워나감
3. K값을 시작으로 좌하단의 K * K 크기의 보드를 전체 순회 및 최소값 연산 진행
4. 최종적으로 최소값을 출력
