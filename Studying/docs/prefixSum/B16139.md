## B 16139 - 인간-컴퓨터 상호작용

**문제 링크 :** https://www.acmicpc.net/problem/16139  
**알고리즘 :** prefixSum  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B16139.java)  

---

### 문제 요약

각 문자별로 누적된 양을 2차원 배열에 보관해 누적합으로 해결하는 문제다.

---

### 핵심 아이디어

- Prefix Sum

---

### 문제 접근 방식

1. 입력받은 값을 char 1차원 배열에 저장
2. 1차원이 입력값의 길이 + 1, 2차원이 알파벳 종류 개수 26인 2차원 정적 배열 생성
3. 입력값의 길이만큼 순회를 돌며 이전값을 계승하고 현재 탐색중인 값의 위치만 1 증가
4. r+1 까지의 누적값에서 l까지의 누적값을 제한값을 StringBuilder에 쌓음
5. 최종적으로 쌓인 값을 출력
