## B 15663 - N과 M (9)

**문제 링크 :** https://www.acmicpc.net/problem/15663  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B15663.java)  

---

### 문제 요약

기본적인 백트래킹 순열 문제다.  
N과 M 시리즈 9번째 문제다.  

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 상태 변화와 복구 처리
- dfs + 가지치기
- 정렬 매커니즘

---

### 문제 접근 방식

1. 정답을 보관하기 위한 2차원 동적 배열 생성
2. 상태 변화를 유효하게 처리하기 위한 방문여부 1차원 배열 선언
3. 깊이는 0부터 시작. 재귀를 통해 점차 증가
4. 재귀 종료 조건을 재귀의 가장 앞쪽에 배치함으로써 불필요한 연산 최소화
5. 정답을 2차원 동적 배열에 저장하고, 최종적으로 출력
