## B 15656 - N과 M (7)

**문제 링크 :** https://www.acmicpc.net/problem/15656  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B15656.java)  

---

### 문제 요약

기본적인 백트래킹 순열 문제다.  
N과 M 시리즈 7번째 문제다.  

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 상태 변화와 복구 처리
- dfs + 가지치기

---

### 문제 접근 방식

1. 정답을 보관하기 위한 1차원 배열을 선언
2. 깊이는 0부터 시작. 재귀를 통해 점차 증가
3. 재귀 종료 조건을 재귀의 가장 앞쪽에 배치함으로써 불필요한 연산 최소화
4. 정답을 전역 StringBuilder에 저장하고 마지막에 출력
