## B 15666 - N과 M (12)

**문제 링크 :** https://www.acmicpc.net/problem/15666  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B15666.java)  

---

### 문제 요약

기본적인 백트래킹 순열 문제다.  
N과 M 시리즈 12번째 문제다.  

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 상태 변화와 복구 처리
- dfs + 가지치기
- 정렬 매커니즘
- 중복 제거

---

### 문제 접근 방식

1. 중복상태를 제거하고 값을 정렬시키기 위한 TreeSet 생성
2. TreeSet으로 만들어진 동적 배열을 연산에 용이하게 하기 위해 정적 배열로 변환
3. 재귀 종료 조건을 재귀의 가장 앞쪽에 배치함으로써 불필요한 연산 최소화
4. 가지치기를 통해 반드시 오름차순으로 값이 저장되도록 유도
5. 저장된 값을 출력
