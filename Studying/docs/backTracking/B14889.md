## B 14889 - 스타트와 링크

**문제 링크 :** https://www.acmicpc.net/problem/14889  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B14889.java)  

---

### 문제 요약

브루트포스와 백트래킹이 혼합된 문제다. 조합을 사용해 해결하였다

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 순서가 무관한 n C (n / 2) 조합
- 백트래킹 + 브루트포스

---

### 문제 접근 방식

1. 조합을 하기 위해 이전값을 기억하는 배열 arr 생성
2. 팀을 boolean을 통해 true 와 false 둘로 나눔
3. 깊이는 0부터 시작. 재귀를 통해 점차 증가
4. depth 가 N/2 이 되면 차이값을 계산
5. 차이값이 기존의 최소값보다 작다면 갱신
6. 최종적으로 최소값 출력
