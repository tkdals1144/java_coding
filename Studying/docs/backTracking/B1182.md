## B 1182 - 부분수열의 합

**문제 링크 :** https://www.acmicpc.net/problem/1182  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B1182.java)  

---

### 문제 요약

브루트포스와 백트래킹이 혼합된 문제다.

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 조합을 위한 index 관리
- 백트래킹 + 브루트포스

---

### 문제 접근 방식

1. 전체 수열을 저장할 1차원 배열 생성
2. 들어갈 깊이를 1~N 까지로 조절해서 백트래킹
3. 상태 변화 및 상태 복구를 위한 sum값 조절
4. sum값이 S와 같다면 count 증가
5. 최종적으로 count 출력
