### 문제 요약

1~N 까지의 모든 순열 구하기  

---

### 핵심 아이디어

- backTracking (dfs + 가지치기)

---

### 4가지 포인트

1. 재귀의 종료 조건 (Base Case) -> 종료 포인트를 재귀의 가장 앞쪽에 설치해 바로 return
2. 상태 변화와 복구 -> 가지치기를 위해 특정 상태를 변화시키고 재귀 이후 복구시킨다
3. 유효성 검사 (가지치기) -> 가능성이 없다면 탐색을 더 진행시키지 않는다
4. 탐색 순서 -> 문제에 따라 어디부터 탐색할지 출력할지를 중요시해야 한다
