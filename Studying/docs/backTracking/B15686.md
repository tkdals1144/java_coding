## B 15686 - 치킨 배달

**문제 링크 :** https://www.acmicpc.net/problem/15686  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B15686.java)  

---

### 문제 요약

모든 치킨집 조합을 구한 후 그 결과값을 이용하는 문제다.  
꽤 어려운 백트래킹 문제였다.  

---

### 핵심 아이디어

- 브루트포스 + 백트래킹
- 치킨집과 집 좌표값을 저장해 탐색시간 최소화
- 치킨집 인덱스를 백트래킹

---

### 문제 접근 방식

1. 치킨집과 집의 좌표값을 ArrayList<int[]> 리스트로 저장
2. 단순 백트래킹을 사용해 접근할 치킨집 인덱스를 저장
3. 깊이는 0부터 시작. 재귀를 통해 점차 증가
4. 깊이가 M이 되었다면 집 좌표를 중심으로 최소가 될 거리값 계산
5. 최소 거리값을 전부 더해서 전역변수 min과 대조
6. 마지막으로 min 출력
