## B 1759 - 암호 만들기

**문제 링크 :** https://www.acmicpc.net/problem/1759  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B1759.java)  

---

### 문제 요약

조건을 만족하는 모든 암호 조합을 만드는 문제다.  

---

### 핵심 아이디어

- 백트래킹 + 조합 + 정렬
- 받아온 예비 암호들을 정렬하여 저장

---

### 문제 접근 방식

1. 알파벳을 입력받은 후 정렬 진행
2. 정렬된 키들을 이용하여 백트래킹 시작
3. depth와 index를 함께 사용하여 조합 백트래킹 진행
4. 깊이가 L이 되었다면 자음과 모음의 개수를 확인
5. 조건을 만족한다면 StringBuilder에 저장
6. 저장된 StringBuilder 값을 출력
