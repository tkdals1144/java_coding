## B 15664 - N과 M (10)

**문제 링크 :** https://www.acmicpc.net/problem/15664  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B15664.java)  

---

### 문제 요약

기본적인 백트래킹 순열 문제다.  
N과 M 시리즈 10번째 문제다.  

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 상태 변화와 복구 처리
- dfs + prev 가지치기
- 정렬

---

### 문제 접근 방식

1. 정답을 보관하기 위한 배열과 수를 보관하기 위한 배열 생성
2. depth, idx를 인자로 dfs 연산 시작
3. 깊이는 0부터 시작. 재귀를 통해 점차 증가
4. 매 dfs마다 prev를 설정하여 동일한 깊이에 동일한 값이 들어올 수 없도록 처리
5. idx를 사용하여 순열이 아닌 조합을 생성
6. 최종적으로 저장된 값을 출력
