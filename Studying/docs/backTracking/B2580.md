## B 2580 - 스도쿠

**문제 링크 :** https://www.acmicpc.net/problem/2580  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B2580.java)  

---

### 문제 요약

평소에 즐겨풀던 스도쿠 문제를 코드로 구현하는 문제다.    

---

### 핵심 아이디어

- dfs + 가지치기를 통한 백트래킹
- 공란 좌표를 저장해두고 재귀 기반으로 사용

---

### 문제 접근 방식

1. 2차원 배열에 현재 스도쿠 퍼즐의 상태를 저장
2. int형 배열을 담는 ArrayList를 통해 공란 좌표들을 전부 저장
3. 0번째 공란부터 탐색 시작. 재귀를 통해 점차 증가
4. 만약 모든 공란이 채워진다면 정답 퍼즐을 출력하고 시스템 자체를 종료
5. 0번째 좌표부터 check 메소드를 통해 들어갈 수 있는 값을 넣고 성공시 +1번째 공란으로 이동
6. 만약 현재 좌표에서 수를 넣는게 불가능하다면 이전 좌표로 돌아와 상태를 공란으로 복구
