## B 9663 - N-Queen

**문제 링크 :** https://www.acmicpc.net/problem/9663  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B9663.java)  

---

### 문제 요약

유명한 N-Queen 백트래킹 문제다.

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 상태 변화와 복구 처리
- dfs + 가지치기

---

### 문제 접근 방식

1. 방문상태를 관리하기 위한 방문 배열 선언
2. 정답 출력을 위한 count = 0 선언
3. row를 기준으로 dfs 재귀
4. col과 대각 두 방향을 방문처리하며 상태변화 및 복구
5. 재귀가 성공적으로 끝까지 도달했다면 count를 증가
6. 최종적으로 정답 출력
