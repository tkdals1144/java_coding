## B 1987 - 알파벳

**문제 링크 :** https://www.acmicpc.net/problem/1987  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B1987.java)  

---

### 문제 요약

격자 그래프에서 백트래킹을 통해 탐색하는 문제다  

---

### 핵심 아이디어

- 백트래킹 + 격자 그래프
- 방문 상태 변화와 복구

---

### 문제 접근 방식

1. 격자 그래프에 문자를 저장
2. 방문할 문자열을 저장할 동적 배열 생성
3. depth를 통해 현재 깊이를 관리하며 최대길이를 전역변수에 저장
4. 방향벡터를 이용하여 그래프를 탐색
5. 방문상태를 변화 및 복구하여 백트래킹 처리
6. 방문 가능한 모든곳을 방문하며 저장된 최대 길이를 출력
