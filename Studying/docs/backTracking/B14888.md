## B 14888 - 연산자 끼워넣기

**문제 링크 :** https://www.acmicpc.net/problem/14888  
**알고리즘 :** backtracking  
**언어 :** JAVA  

[ 코드 보기 ](../../src/backTracking/B14888.java)  

---

### 문제 요약

브루트포스와 백트래킹이 혼합된 문제다.

---

### 핵심 아이디어

- 재귀의 종료 조건 처리
- 연산자 개수의 변화와 복구
- 백트래킹 + 브루트포스

---

### 문제 접근 방식

1. 오염되지 않은 value값을 보존하기 위해 1차원 배열 생성
2. 최소값과 최대값이 +-10억을 넘지 않기에 최소값과 최대값을 int의 max, min 값으로 초기화
3. 깊이는 0부터 시작. 재귀를 통해 점차 증가
4. 모든 연산자를 넣으면 재귀 종료. 값을 확인해 최소값, 최대값 여부 확인
5. 연산자가 부족하다면 continue
6. 연산된 값을 value 배열에 보관
7. 최종적으로 최대값, 최소값 출력
