## B 2636 - 치즈

**문제 링크 :** https://www.acmicpc.net/problem/2636  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B2636.java)  

---

### 문제 요약

2차운 격자 그래프에서 치즈가 녹는 시간과 마지막까지 남은 치즈의 개수를 구하는 문제다.

---

### 핵심 아이디어

- 2차원 격자 그래프
- 시간을 저장할 2차원 배열
- 치즈를 중심으로 한 치즈 녹이기

---

### 문제 접근 방식

1. 외부와 접촉된 공백공간인지 아닌지를 구별 필요
2. 출력에 마지막 남은 치즈가 필요하기에 치즈가 녹은 자리인지 공백인지 구별 필요
3. 마지막 남은 치즈를 구하기 위한 2차원 시간 배열 생성
4. bfs를 통해 외부와 접촉된 빈 공간을 매 루프마다 초기화
5. 가장 외부의 치즈를 걷어내면서 시간을 1 씩 증가
6. 최종적으로 모든 치즈가 걷어내질때 시간과 시간과 맞는 치즈를 출력

---

### 시간복잡도
- **O(N * M)**
