## B 18352 - 특정 거리의 도시 찾기

**문제 링크 :** https://www.acmicpc.net/problem/18352   
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B18352.java)  

---

### 문제 요약

간단한 가중치 없는 단방향 그래프 탐색 문제다

---

### 핵심 아이디어

- BFS 탐색
- 각 위치별 거리 탐색 및 저장

---

### 문제 접근 방식

1. ArrayList의 정적 배열과 int 정적 배열을 선언하여 그래프와 거리값 저장
2. bfs 탐색을 통해 각 위치별 거리값 저장
3. 정답 도출을 위한 거리값에 맞는 정점이 있다면 출력
4. 없다면 sb.length() 길이가 0 인 점을 이용해 if문으로 -1 출력

---

### 시간복잡도
- **O(N + M)**
