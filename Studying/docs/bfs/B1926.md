## B 1926 - 그림

**문제 링크 :** https://www.acmicpc.net/problem/1926  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B1926.java)  

---

### 문제 요약

격자 그래프에서 방향벡터를 이용해 탐색하는 문제다.  
전체 영역의 개수와 가장 큰 영역을 출력한다.

---

### 핵심 아이디어

- 격자 그래프에서의 탐색 이동을 위한 방향벡터 구현
- 모든 좌표에 대한 BFS 탐색

---

### 문제 접근 방식

1. 영역을 표시하기 위한 graph와 탐색 여부를 나타내기 위한 visited 2차원 배열 구현
2. 영역이 1이고 미탐색인 구간에 대한 전체 탐색 실시
3. BFS 함수 실행시 영역개수 1 증가
4. 격자 그래프의 탐색이 끝난 이후 마지막으로 최대값인지 확인
5. 연산이 종료된 후 결과값 출력

---

### 시간복잡도
- **O(n x m)**
