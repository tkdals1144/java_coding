## B 5014 - 스타트링크

**문제 링크 :** https://www.acmicpc.net/problem/5014  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B5014.java)  

---

### 문제 요약

1차원 배열에서 bfs를 통해 탐색하는 문제다

---

### 핵심 아이디어

- 1차원 그래프 배열
- 증감치에 따른 bfs 탐색 

---

### 문제 접근 방식

1. 1차원 배열을 선언 후, 방문처리를 수월하게 하기 위해 모든 값을 -1로 초기화
2. 큐에 초기값을 넣고 거리를 0으로 초기화
3. 큐에서 빼낸 값을 증감치에 따라 이동처리
4. 정답값이 도출되었다면 바로 함수를 종료
5. 도출된 정답을 출력
