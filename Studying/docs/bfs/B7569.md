## B 7569 - 토마토

**문제 링크 :** https://www.acmicpc.net/problem/7569  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B7569.java)  

---

### 문제 요약

3차원 격자 그래프에서 익은 토마토로부터 인접한 토마토가 하루마다 익어가는 문제다.   
그렇게 전체가 익는데 얼마의 시간이 걸리는지 도출하는 문제다.  

---

### 핵심 아이디어

- 3차원 정적 배열과 6방향 방향벡터 구현
- 익은 토마토들을 중심으로 BFS 동시 확산
- 익는 데 걸린 날짜를 정적 배열에 저장

---

### 문제 접근 방식

1. H * N * M 크기의 3차원 정적 배열에 토마토 상태 저장
2. dist 정적 배열을 선언하여 날짜를 카운트
3. 날짜별로 익은 토마토를 큐에 삽입하여 연산
4. 3차원 BFS 탐색
5. 큐가 빌 때까지 전체를 탐색 후 익지 못한것이 있는지 검사 후 출력

---

### 시간복잡도
- **O(H * N * M)**
