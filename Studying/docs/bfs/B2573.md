## B 2573 - 빙산

**문제 링크 :** https://www.acmicpc.net/problem/2573  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B2573.java)  

---

### 문제 요약

격자 그래프가 분리되는지, 분리된다면 어느정도의 시간이 걸리는지에 대해 결과를 도출하는 문제다.  
연결된 격자 그래프의 값들을 관리하는게 핵심이다.  

---

### 핵심 아이디어

- 각 좌표별로 감소치 계산
- bfs 탐색을 통한 연결여부 확인

---

### 문제 접근 방식

1. 불필요한 삽입, 삭제 연산을 최소화하기 위해 각 빙산별 감소 가중치를 저장
2. 방문 여부 확인을 위한 그래프, 실제 빙산의 높이를 저장하기 위한 그래프를 선언
3. 모든 빙산을 가중치에 따라 높이 감산을 진행
4. 빙산이 하나라도 높이가 0이 되는 순간 bfs 탐색을 통해 연결여부를 확인
5. 연결여부를 확인하여 비연결 상태라면 연도를 출력
6. 모든 빙산이 녹아 사라진다면 0을 출력

---

### 시간복잡도

- **O(N * M)**
