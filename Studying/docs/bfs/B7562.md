## B 7562 - 나이트의 이동

**문제 링크 :** https://www.acmicpc.net/problem/7562  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B7562.java)  

---

### 문제 요약

체스판에서 나이트의 최소 이동 횟수를 구하는 문제다.   
출발 지점에서 목표 지점까지 나이트의 이동 규칙에 맞게 탐색한다.  

---

### 핵심 아이디어

- 나이트의 이동 규칙에 맞춰 8방향 방향 벡터 구현
- 모든 방향에 대한 BFS 탐색

---

### 문제 접근 방식

1. I * I 크기의 2차원 정적 배열을 생성 후 미방문 칸을 -1로 초기화
2. 나이트 이동 규칙에 맞춘 8방향 방향 벡터 구현
3. BFS 탐색 실시
4. 탐색 종료 후 목표 위치의 거리값을 출력

---

### 시간복잡도
- **O(I * I)**
