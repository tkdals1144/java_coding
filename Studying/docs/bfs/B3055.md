## B 3055 - 탈출

**문제 링크 :** https://www.acmicpc.net/problem/3055  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B3055.java)  

---

### 문제 요약

격자 그래프에 물을 피해 고슴도치가 비버의 굴로 탈출하는 문제다.  
물이 번질 곳으로는 비버가 이동할 수 없다는것에 집중해야 한다.  

---

### 핵심 아이디어

- 2차원 격자 그래프
- 물이 번지는 시간을 먼저 저장
- 물이 번진 시간을 기준으로 고슴도치의 통과 여부 결정

---

### 문제 접근 방식

1. 두개의 bfs를 동시에 굴려야 한다고 생각
2. 두개의 bfs가 동시에 굴러가는것처럼 보이도록 하나의 시간 그래프를 공유
3. 먼저 물이 번지도록 waterBfs 메소드를 실행해 물이 번진 시간을 저장
4. escapeBfs 메소드를 실행하여 물이 번진 시간과 비교해 이동 가능한지 결정
5. return 값으로 boolean 을 줘서 탈출 가능/불가능 여부 확인
6. 가능하다면 endpoint의 time 값을 불가능하다면 "KAKTUS" 를 출력
