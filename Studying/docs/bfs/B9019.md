## B 9019 - DSLR

**문제 링크 :** https://www.acmicpc.net/problem/9019  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B9019.java)  

---

### 문제 요약

역추적 알고리즘을 섞은 BFS 문제다.  
어렵지는 않지만 구현할게 많아 실수를 주의해야 했다.

---

### 핵심 아이디어

- BFS
- Node 역추적

---

### 문제 접근 방식

1. Node를 값과 입력 그리고 다음 노드를 가리키는 형태로 생성
2. 무한 재귀를 막기 위해 visited 배열 생성
3. 각 연산에 맞는 메소드를 생성
4. 연산을 하나씩 큐에 넣되, 이미 탐색한 위치라면 더 탐색하지 않음
5. end 값이 나오면 break
6. ArrayList에 값을 쌓고 이를 역순으로 StringBuilder에 쌓음
7. 최종적으로 쌓인 값을 출력
