## B 2146 - 다리 만들기

**문제 링크 :** https://www.acmicpc.net/problem/2146  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B2146.java)  

---

### 문제 요약

격자 그래프에서 방향벡터를 이용해 탐색하는 문제다.  
각 섬들을 라벨링하고 다른 섬에 닿았을 때, 가장 작은 dist값을 구하는 문제다.

---

### 핵심 아이디어

- 격자 그래프에서의 탐색 이동을 위한 방향벡터 구현
- 모든 좌표에 대한 BFS 탐색
- 지금 탐색하는 섬을 저장할 임시 배열

---

### 문제 접근 방식

1. 영역을 표시하기 위한 graph와 탐색 여부를 나타내기 위한 visited 2차원 배열 구현
2. 매 탐색마다 현재 섬을 제외한 모든 좌표의 dist값을 -1로 초기화
3. bfsFrist를 통해 섬을 라벨링하고, bfs탐색을 통해 다른 섬까지의 거리를 저장
4. 탐색한 섬은 visited를 true로 설정해 다시 탐색하지 않도록 설정
5. 연산 종료 후 거리 최소값 출력

---

### 시간복잡도
- **O(n x m)**
