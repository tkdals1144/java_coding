## B 16928 - 뱀과 사다리 게임

**문제 링크 :** https://www.acmicpc.net/problem/16928   
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B16928.java)  

---

### 문제 요약

일차원 그래프에서 각 구간별 거리값을 저장하는 BFS 문제다

---

### 핵심 아이디어

- 거리값을 저장할 일차원 배열과 뱀과 사다리 이동값을 저장할 일차원 배열
- 뱀, 사다리를 유의하며 BFS 탐색

---

### 문제 접근 방식

1. 거리값과 순간이동값을 저장할 일차원 배열 두개를 선언
2. BFS 탐색을 기본적으로 거리값을 1을 증가시키며 연산
3. 뱀이나 사다리를 만나면 위치를 순간이동할 위치로 하고 해당 거리값을 1 증가시켜 저장
4. 문제에서 요하는 100번째의 거리값을 출력

---

### 시간복잡도
- **사실상 O(1)**
