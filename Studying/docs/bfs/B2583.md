## B 2583 - 영역 구하기

**문제 링크 :** https://www.acmicpc.net/problem/2583   
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B2583.java)  

---

### 문제 요약

격자 그래프에 여러개의 직사각형이 칠해져 있을 때, 남은 빈 영역들의 개수와 넓이를 구하는 문제다.  

---

### 핵심 아이디어

- 격자 그래프에서 방문하지 않은 빈 칸을 발견하면 BFS 탐색을 시작
- BFS를 통해 연결된 영역을 모두 탐색하며 넓이를 카운트

---

### 문제 접근 방식

1. 그래프를 N * M 크기의 2차원 정적 배열로 선언
2. 방문한 칸을 1로 표시하며 큐에 삽입
3. 그래프를 전체 순회하며 0인 칸 발견 시 BFS 실행
4. BFS 탐색 결과를 동적 배열에 저장
5. 연산 종료 후 영역의 개수와 넓이를 정렬 후 출력

---

### 시간복잡도
- **O(N * M)**
