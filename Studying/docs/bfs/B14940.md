## B 14940 - 쉬운 최단거리

**문제 링크 :** https://www.acmicpc.net/problem/14940   
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B14940.java)  

---

### 문제 요약

이차원 그래프에서 목표지점까지의 모든 지점의 거리를 구하는 문제다

---

### 핵심 아이디어

- 이차원 배열과 방향벡터
- BFS 탐색
- 각 위치의 거리값 계산

---

### 문제 접근 방식

1. 모든 값에 대한 BFS 연산을 한다고 가정하면 시간복잡도가 O(N^2*M^2) 이기에 불가능하다고 생각
2. 목표 지점을 시작점으로 잡는다면 한번의 연산으로 해결 가능
3. 목표 지점을 시작점으로 BFS 연산
4. 출력 양식에 갈 수 없는 땅은 0, 도달 불가능은 -1인 부분을 조심
5. 연산 종료 후 결과값을 StringBuilder로 출력

---

### 시간복잡도
- **O(N*M)**
