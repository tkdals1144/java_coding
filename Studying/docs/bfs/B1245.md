## B 1245 - 농장 관리

**문제 링크 :** https://www.acmicpc.net/problem/1245  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B1245.java)  

---

### 문제 요약

격자 그래프에서 솟아오른 산봉우리의 개수를 새는 문제다.

---

### 핵심 아이디어

- 이차원 격자 그래프
- BFS 탐색
- 최대값으로부터 값 내려가기

---

### 문제 접근 방식

1. 산의 높이와 방문여부를 저장할 각각의 2차원 배열 생성
2. 산봉우리가 높은순부터 낮은순으로 연산
3. BFS를 통해 높이가 같거나 낮은것들을 소모
4. 방문이 되지 않은 지형이 있다면 계속 연산
5. 연산 종료 후 결과값 출력
