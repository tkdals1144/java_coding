## B 5567 - 결혼식

**문제 링크 :** https://www.acmicpc.net/problem/5567  
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B5567.java)  

---

### 문제 요약

bfs 탐색을 진행하되 깊이가 2인것까지만 출력하는 문제다.  

---

### 핵심 아이디어

- 탐색 여부 체크, 깊이 관리, 큐를 통한 bfs 탐색
- 모든 좌표에 대한 BFS 탐색

---

### 문제 접근 방식

1. 기존의 다른 bfs 문제들처럼 ArrayList 배열을 선언해서 정점 연결
2. 모든 깊이를 Arrays.fill 을 통해 1로 초기화
3. bfs 탐색을 통해 각 정점의 깊이값을 도출
4. 깊이가 2 이하인 정점을 확인시 count를 1 증가
5. count 출력

---

### 시간복잡도
- **O(N + M)**
