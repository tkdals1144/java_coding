## B 2589 - 보물섬

**문제 링크 :** https://www.acmicpc.net/problem/2589   
**알고리즘 :** BFS  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bfs/B2589.java)  

---

### 문제 요약

지도에서 두 정점 사이의 이동거리가 가장 긴 두 정점의 이동거리를 구하는 문제다  

---

### 핵심 아이디어

- 50 * 50 크기의 격자 그래프기에 완전 탐색이 유효함
- BFS를 통해 각 정점간의 이동거리를 계산

---

### 문제 접근 방식

1. 거리와 상태를 저장하기 위한 각각의 2차원 격자 그래프 선언
2. 50 * 50 크기의 작은 그래프기에 완전탐색을 사용
3. 매 BFS 연산마다 Arrays.fill 을 통해 dist값을 -1로 초기화
4. 가장 큰 값을 매 연산마다 확인 후 저장
5. 저장된 값을 출력

---

### 시간복잡도
- **O(N * M)**
