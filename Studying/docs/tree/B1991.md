## B 1991 - 트리 순회

**문제 링크 :** https://www.acmicpc.net/problem/1991  
**알고리즘 :** tree  
**언어 :** JAVA  

[ 코드 보기 ](../../src/tree/B1991.java)  

---

### 문제 요약

문제에 따라 트리를 구현하고 이를 순회하는 문제다  

---

### 핵심 아이디어

- Linked Binary Tree
- 재귀

---

### 문제 접근 방식

1. 순회에 사용할 구조체 Node 생성
2. 중복 저장을 피하기 위해 putIfAbsent로 map에 노드를 저장
3. left, right 값도 노드에 함께 저장
4. 전위 순회, 중위 순회, 후위 순회 로직을 구현
5. 루트를 A 로 설정하고 각각의 순회 진행
6. 순회를 통해 쌓인 값을 최종적으로 출력
