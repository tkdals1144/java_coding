## B1967 - 트리의 지름

**문제 링크 :** https://www.acmicpc.net/problem/1967  
**알고리즘 :** tree  
**언어 :** JAVA  

[ 코드 보기 ](../../src/tree/B1967.java)  

---

### 문제 요약

dfs를 이용하여 트리의 지름을 구하는 문제다

---

### 핵심 아이디어

- dfs
- backTraking
- linkedList

---

### 문제 접근 방식

1. 순회에 사용할 구조체 Node 생성
2. 방문처리를 위해 visited 배열 생성
3. 입력에 따라 Node 리스트를 연결
4. 백트래킹을 통해 그래프를 전체 탐색하며 최대 이동거리를 저장
5. 저장된 최대 이동거리를 출력
