### 문제 접근 방식

1. 각 주유소의 비용과 길의 가중치를 저장한 배열을 선언
2. 주유소의 비용을 현재의 최소비용과 비교한 후 최소비용으로 당장 앞의 길의 값을 계산
3. 계산된 값을 count에 누적
4. 최종적으로 count를 출력
