## B 1931 - 회의실 배정

**문제 링크 :** https://www.acmicpc.net/problem/1931  
**알고리즘 :** greedy  
**언어 :** JAVA

---

### 문제 요약

그리디 알고리즘의 핵심을 찌르는 문제다.
문제가 그리디임을 확인하지 못하면 풀기 어렵다.

---

### 핵심 아이디어

- 그리디 알고리즘

---

### 문제 접근 방식

1. 이 문제는 회의가 빨리 끝나야 이후가 가능한 많은 회의를 진행할 수 있음을 이해해야 한다
2. 회의에 대한 데이터를 2차원 데이터로 선언
3. 회의가 일찍 끝나는 순으로 오름차순 정렬 (회의가 끝나는 시간이 같다면 회의가 시작하는 시간을 기준으로 재정렬)
4. 회의가 일찍 끝나는 순으로 회의를 진행하고 count 값을 증가
5. 최종적으로 count값을 출력
