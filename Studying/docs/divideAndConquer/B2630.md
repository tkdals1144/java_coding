## B 2630 - 색종이 만들기

**문제 링크 :** https://www.acmicpc.net/problem/2630  
**알고리즘 :** divide and conquer  
**언어 :** JAVA  

[ 코드 보기 ](../../src/greedy/B2630.java)  

---

### 문제 요약

분할 정복의 기초를 다루는 문제
일단 알고리즘 이해를 위해 답지를 까고 풀었다
분할정복은 일단 재귀와 브레이크 포인트가 핵심이다
그 중에서도 특히 브레이크 포인트를 제대로 설정하지 못한다면 무한루프를 돌며 에러가 발생한다

---

### 핵심 아이디어

- 분할 정복

---

### 문제 접근 방식

1. 전체 데이터를 저장할 2차원 배열을 생성
2. 나눌 위치에 맞춰 그래프를 4등분하도록 재귀함수를 생성
3. 나눈 종이가 모두 같은지 확인 (breakPoint)
4. 모두 같다면 어떤 종이로 같은지 확인 후 해당 count값을 상승
5. 최종적으로 countWhite와 countBlue를 출력
