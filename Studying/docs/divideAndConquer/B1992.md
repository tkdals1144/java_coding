### 문제 접근 방식

1. 전체 데이터를 저장할 2차원 배열을 생성
2. 나눌 위치에 맞춰 그래프를 4등분하도록 재귀함수를 생성
3. 4등분한 재귀위치 앞뒤에 '(' 와 ')' 를 StringBuilder에 쌓음
3. 나눈 그래프가 모두 같은지 확인 (breakPoint)
4. 모두 같다면 StringBuilder 에 해당 값을 쌓음
5. 최종적으로 StringBuilder에 쌓인 값을 출력
