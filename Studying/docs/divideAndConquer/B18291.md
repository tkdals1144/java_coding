## B 18291 - 행렬 제곱

**문제 링크 :** https://www.acmicpc.net/problem/18291  
**알고리즘 :** divide and conquer  
**언어 :** JAVA

### 문제 요약

굉장히 흥미롭고 재밌는 문제다.
조합론과 거듭제곱 분할정복을 엮은 문제다.

---

### 핵심 아이디어

- 분할 정복
- 조합론

---

### 문제 접근 방식

1. 문제에 대한 조건을 통해 패턴을 확인
2. n-2 C 0 + n-2 C 1 + n-2 C 2 + ... + n-2 C c-2 임을 확인
3. 위의 계산결과가 2 ^ (n-2) 임을 확인
3. 거듭제곱을 분할정복할 divide 함수를 만들고 size를 이용
4. size를 2로 나눠 나머지가 1이라면 한번 더 곱함
5. 최종적으로 StringBuilder에 결과 행렬을 쌓아서 출력
