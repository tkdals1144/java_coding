### 문제 요약

거듭 제곱을 분할 정복으로 처리하는 문제다.  
규칙만 발견한다면 아주 쉽다.

---

### 핵심 아이디어

- 분할 정복

---

### 문제 접근 방식

1. 직접 테스트케이스를 적으며 규칙을 확인
2. 확인한 규칙을 통해 정답이 2^(N-1) 임을 확인
3. MOD 를 final로 둬서 사용
4. size == 0, size == 1 에서 각각 1, 2 를 리턴
5. half를 미리 계산해서 재활용 (시간 단축)
6. size가 홀수일 경우를 감안해서 코딩
7. 최종적으로 pow(N-1) 을 출력
