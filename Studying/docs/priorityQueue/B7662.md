## B 7662 - 이중 우선순위 큐

**문제 링크 :** https://www.acmicpc.net/problem/7662  
**알고리즘 :** priorityQueue  
**언어 :** JAVA  

[ 코드 보기 ](../../src/priorityQueue/B7662.java)  

---

### 문제 요약

이중 우선순위 큐를 구현하는 문제다  
일반적인 우선순위 큐는 한 방향의 우선순위만 제어할 수 있어서 두 개의 큐를 동기화하여 관리해야 한다

---

### 핵심 아이디어

- priorityQueue

---

### 문제 접근 방식

1. 우선순위큐 두 개와 각 숫자의 빈도수를 저장할 TreeMap<Integer, Integer>을 준비
2. 입력 신호시 두 큐 모두에 값을 넣고, map에서 해당 숫자의 count 1 증가
3. 제거 신호가 1이면 maxPQ로부터 -1이면 minPQ로부터 값을 제거
4. map의 count가 0인 값들은 이미 다른 큐에 의해 삭제된 것이므로 poll()을 반복하며 유효한 값을 탐색
5. 유효한 값 탐색시 count를 1 감소
6. 연산 종료 후 실제로 map에 값이 존재하는지 peek로 확인 후 없으면 poll로 제거
7. 큐가 비었다면 EMPTY를 아니라면 최대값과 최소값을 StringBuilder에 누적
8. 최종적으로 출력
