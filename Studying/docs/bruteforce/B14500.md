## B 14500 - 테트로미노

**문제 링크 :** https://www.acmicpc.net/problem/14500  
**알고리즘 :** bruteforce  
**언어 :** JAVA  

[ 코드 보기 ](../../src/bruteforce/B14500.java)  

---

### 문제 요약

브루트포스와 백트래킹이 결합된 문제다.
예외 구조인 ㅏ 모양을 유의해야 한다.

---

### 핵심 아이디어

- bruteforce
- backtraking

---

### 문제 접근 방식

1. 방향벡터 dy[] dx[] 를 생성
2. 그래프의 상태를 저장할 2차원 graph 함수와 방문상태를 저장할 2차원 visited 함수 생성
3. 재귀적으로 백트래킹을 진행할 dfs 함수 생성
4. count가 4가 되면 break (breakpoint) 
5. 추후 연산에서 문제가 되지 않도록 방문 상태를 false로 정리
6. 예외 모양을 연산하기 위해 따로 탐색 함수를 하나 생성
7. 저장된 최대값을 출력
