### 문제 접근 방식

1. 거리값 갱신 이전 최대값 INF 설정
2. 자기 자신으로부터 자기 자신까지의 거리는 0으로 초기화
3. 입력대로 거리값 설정
4. 모든 정점에 대해 a -> c 를 a -> b -> c 와 비교하여 최소값으로 초기화
5. 저장된 최소값을 전부 출력
