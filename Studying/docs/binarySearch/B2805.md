## B 2805 - 나무 자르기

**문제 링크 :** https://www.acmicpc.net/problem/2805  
**알고리즘 :** binary search  
**언어 :** JAVA  

[ 코드 보기 ](../../src/binarySearch/B2805.java)  

---

### 문제 요약

이분 탐색을 통해 자를 나무의 높이를 구하는 문제다.
이분 탐색의 기본을 익히기 좋았다.

---

### 핵심 아이디어

- 이분 탐색

---

### 문제 접근 방식

1. N, M 값과 tree의 값을 저장할 공간 생성
2. 나무를 자를 가장 낮은값을 left 로 가장 높은값을 right 로 설정
3. left <= right 를 만족하는 동안 계속 반복 진행
4. 이분 탐색의 핵심인 mid 를 left + right 의 절반으로 설정
5. 정답구조를 만족하는지 나무 배열을 돌려 진행
6. 만족한다면 일단 정답값으로 저장하고 최소값 left를 높임
7. 만족하지 못한다면 최대값 right를 낮춤
8. 최종적으로 정답값을 출력
