Well-known 문제다.

- dp (배낭)

---

### 문제 접근 방식

1. 입력값을 받을 coins배열과 goal배열을 1차원 정적으로 생성
2. goal은 기본적인 배낭문제와 같이 금액을 index로 설정
3. 아무것도 선택하지 않는 초기값 0원을 1번 선택인 goal[0] = 1 로 설정
4. 각 코인별로 누적시키면서 dp배열인 goal배열을 채워나감
5. 목표 금액인 goal[goal.length-1]의 값을 StringBuilder 에 쌓음
6. 쌓은 값을 최종적으로 출력
