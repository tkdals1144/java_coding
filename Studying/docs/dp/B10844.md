## B 10844 - 쉬운 계단 수

**문제 링크 :** https://www.acmicpc.net/problem/10844  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B10844.java)  

---

### 문제 요약

논리에 따라 2차원 dp를 짜야하는 문제

---

### 핵심 아이디어

- 2차원 dp

---

### 문제 접근 방식

1. 현재 자릿수를 첫번째 차원에 해당 자릿수에 해당하는 수를 두번째 차원에 저장
2. 이렇게 저장된 2차원 배열에 각각 누적된 값을 저장
3. 끝이 0이나 9가 되는 경우는 이전에 끝이 1이나 8인 경우뿐이기에 먼저 연산
4. 남은 자리수를 순회를 돌리며 합산 연산 진행
5. 마지막으로 N번째 차원에 각 수들을 순회를 돌며 누적하여 값을 출력
