## B 9184 - 신나는 함수 실행

**문제 링크 :** https://www.acmicpc.net/problem/9184  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B9184.java)  

---

### 문제 요약

재귀 의사코드를 dp로 바꾸는 문제. 
구현 난이도가 살짝 있었다.

---

### 핵심 아이디어

- 3차원 dp 배열
- 단순 구현

---

### 문제 접근 방식

1. 문제에서 정의된 의사코드를 토대로 코딩
2. 조건에 맞춰 알맞은 값을 dp에 저장
3. 저장된 dp값을 StringBuilder를 이용해 값을 쌓음
4. 최종적으로 -1, -1, -1 입력시 출력
