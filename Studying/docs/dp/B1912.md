## B 1912 - 연속합

**문제 링크 :** https://www.acmicpc.net/problem/1912  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B1912.java)  

---

### 문제 요약

연속된 누적합을 확인하며 dp를 갱신하는 문제다

---

### 핵심 아이디어

- 누적합
- dp

---

### 문제 접근 방식

1. 실제 값을 저장할 1차원 배열 선언
2. 누적합을 저장할 dp 1차원 배열 선언
3. 현재 값과 누적합과 더 높은 값을 비교해서 dp에 저장
4. 저장과 동시에 최대값과 비교연산을 실시하여 최대값을 저장
5. 저장된 최대값을 출력
