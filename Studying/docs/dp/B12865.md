## B 12865 - 평범한 배낭

**언어 :** JAVA

### 문제 요약

무게를 index로 활용하는 2차원 dp 문제  
well-known 문제라 그런지 해답을 보고 구현하였다

---

### 핵심 아이디어

- dp (배낭 문제)

---

### 문제 접근 방식

1. dp(i)(w) => i번째 물건 (0 ~ i) 을 고려했을 때, 무게 w 이하로 얻을 수 있는 최대 가치
2. 가장 첫번째 초기화를 위해 0번째 물건을 넣어 dp 상태를 초기화
3. 현재 탐색중인 물건의 무게가 탐색중인 무게 인덱스 w보다 낮은 상태라면 물건을 집어넣어봄
4. 물건을 넣을지 말지 Math.max를 이용
5. 만약 탐색중인 물건의 무게가 탐색중인 무게 인덱스 w보다 높다면 넣을수 없으므로 이전값 계승
6. 최종적으로 dp(N - 1)(K) 출력
