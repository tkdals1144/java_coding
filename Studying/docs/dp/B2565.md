## B 2565 - 전깃줄

**언어 :** JAVA

---

### 문제 요약

lis를 적극 활용하는 문제.  
lis임을 확인하는것이 문제의 핵심이다.  

---

### 핵심 아이디어

- dp (lis)

---

### 문제 접근 방식

1. 문제 조건에 맞는 inner 클래스 하나 생성
2. A 전봇대의 기준에 맞춰 배열값들을 오름차순 정렬
3. index+1 길이에 들어갈 수 있는 최소크기의 값을 넣는 lis 배열 생성
4. 바이너리서치를 통해 들어갈 위치를 계산 후, 최소크기를 대체
5. lis에 들어간 크기만큼 size값을 늘림
6. 최종적으로 N - size (총 크기 - 존재 가능한 크기) 를 출력
