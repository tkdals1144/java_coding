## B 1932 - 정수 삼각형

**문제 링크 :** https://www.acmicpc.net/problem/1932  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B1932.java)  

---

### 문제 요약

2차원 dp를 연습하기 아주 좋은 문제다

---

### 핵심 아이디어

- 2차원 dp
- 분기설정

---

### 문제 접근 방식

1. 본래 2차원 dp로 푸는것이 권장되는 문제지만 메모리 최적화를 위해 1차원 dp로 해결해보기로 생각
2. 2차원의 index를 1차원으로 풀고, 2중 for문에 3개의 값을 증가연산 시키면 index를 관리
3. 첫번째 값과 양 옆 테두리 그리고 삼각형 내부로 각각 분기 설정
4. 분기에 맞춰 dp 누적값 설정 및 최대값 매 순회마다 갱신
5. 저장된 최대값을 출력
