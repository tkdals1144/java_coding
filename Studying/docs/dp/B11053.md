## B 11053 - 가장 긴 증가하는 부분 수열

**문제 링크 :** https://www.acmicpc.net/problem/11053  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B11053.java)  

---

### 문제 요약

dp 배열에 실제 값과 카운트수를 함께 저장해서 푸는 문제다

---

### 핵심 아이디어

- 2차원 dp

---

### 문제 접근 방식

1. 2차원 배열의 첫 차원에 인덱스를 두번째 차원에 실제 값과 카운트를 저장
2. 모든 값들은 수열의 가장 첫번째가 될 수 있기에 카운트 기본값으로 1을 입력
3. 2중 for문으로 순회를 돌며 현재 위치와 이전 위치들을 비교하며 연산 진행
4. temp로 저장된 임시 카운트값을 현재 인덱스의 카운트에 추가
4. 최종적으로 모든 인덱스를 돌며 가장 높은 카운트값을 출력
