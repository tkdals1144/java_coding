## B 3745 - 오름세

**문제 링크 :** https://www.acmicpc.net/problem/3745  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B3745.java)  

---

### 문제 요약

lis를 적극 활용하는 문제.  
기본 lis 문제에 EOF가 추가되었다.

---

### 핵심 아이디어

- dp (lis)
- 이분탐색을 통한 인덱스 확인
- EOF

---

### 문제 접근 방식

1. 입력값과 lis를 저장할 배열을 각각 생성
2. lis의 사이즈를 외부에 두어 관리
3. 입력값이 더 들어오지 않을때까지 계속해서 반복연산 (공백값도 처리하기 위해 trim도 사용)
4. 현재 lis의 마지막 값과 비교하여 증가상태라면 사이즈를 늘리고 마지막 인덱스에 값을 부여
5. 감소한다면 이분탐색을 통해 가장 최적인 위치를 찾아 해당 위치에 삽입 (사이즈는 그대로)
6. size값을 StringBuilder에 쌓고, 최종적으로 쌓인값을 출력
