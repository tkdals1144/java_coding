### 문제 요약

---

### 문제 접근 방식

1. 처음으로 1 ~ 5 까지의 수를 대입하며 값을 얻음
2. 규칙을 통해 마지막 타일로 무엇을 선택하느냐로 값이 변동됨을 확인
3. f(n) = f(n-1) + f(n-2)
4. 위 공식을 dp 기술을 사용하여 구현
