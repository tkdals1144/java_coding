## B 1818 - 책정리

**문제 링크 :** https://www.acmicpc.net/problem/1818  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B1818.java)  

---

### 문제 요약

lis를 적극 활용하는 문제.  
lis 배열을 채워가며 배열값이 덮어씌워진 횟수를 출력하면 된다.

---

### 핵심 아이디어

- dp (lis)
- 이분탐색을 통한 인덱스 확인

---

### 문제 접근 방식

1. 입력값과 lis를 저장할 배열을 각각 생성
2. lis의 사이즈를 외부에 두어 관리
3. 현재 lis의 마지막 값과 비교하여 증가상태라면 사이즈를 늘리고 마지막 인덱스에 값을 부여
4. 감소한다면 이분탐색을 통해 가장 최적인 위치를 찾아 해당 위치에 삽입 (사이즈는 그대로)
5. 최적인 위치를 찾아 삽입했다면 count 값을 1 증가
6. 최종적으로 count 값을 출력
