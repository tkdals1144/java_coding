## B 11054 - 가장 긴 바이토닉 부분 수열

**문제 링크 :** https://www.acmicpc.net/problem/11054  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B11054.java)  

---

### 문제 요약

dp 배열에 실제 값과 카운트수를 함께 저장해서 푸는 문제다
푸는데 꽤 애먹었다. dp문제 으려워...

---

### 핵심 아이디어

- 2차원 dp
- 연산상태 저장

---

### 문제 접근 방식

1. 2차원 배열의 첫 차원에 인덱스를 두번째 차원에 실제 값과 증가 카운트와 감소 카운트를 저장
2. 모든 값들은 수열의 가장 첫번째가 될 수 있기에 카운트 기본값으로 1을 입력
3. 2중 for문으로 순회를 돌며 현재 위치와 이전 위치들을 비교하며 연산을 총 2회 진행
4. temp로 저장된 임시 카운트값을 현재 인덱스의 카운트에 추가
5. 최종적으로 모든 인덱스를 돌며 해당 인덱스의 증가 카운트와 감소 카운트를 더한 값에서 1을 뺀 값들중 가장 큰 값을 출력
