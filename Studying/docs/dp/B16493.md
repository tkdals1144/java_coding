## B 16493 - 최대 페이지 수

**문제 링크 :** https://www.acmicpc.net/problem/16493  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B16493.java)  

---

### 문제 요약

기본적인 0-1 냅색문제다.  
well-known 문제다.

---

### 핵심 아이디어

- 배낭 문제
- 2차원 dp

---

### 문제 접근 방식

1. dp(i)(w) => i번째 책 (0 ~ i) 을 고려했을 때, 날짜 w 이하로 얻을 수 있는 최대 가치
2. 2차원 그래프를 머리로 그려 조건에 맞는 부분을 채우고 아닌 부분은 계승하는 방식을 생각
2. 가장 첫번째 초기화를 위해 0번째 문제를 넣어 dp 상태를 초기화
3. 현재 탐색중인 문제의 시간이 탐색중인 시간 인덱스보다 낮은 상태라면 책을 집어넣어봄
4. 문제를 넣을지 아니면 기존것을 계승할지 Math.max를 이용
5. 만약 탐색중인 문제의 시간이 탐색중인 시간 인덱스보다 높다면 넣을수 없으므로 이전값 계승
6. 최종적으로 마지막에 제대로 쌓인 dp(M - 1)(N) 출력
