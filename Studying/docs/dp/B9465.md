## B 9465 - 스티커

**문제 링크 :** https://www.acmicpc.net/problem/9465  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B9465.java)  

---

### 문제 요약

간단한 2차원 dp 문제다

---

### 핵심 아이디어

- 2차원 dp

---

### 문제 접근 방식

1. 2차원 dp 배열을 생성하고 입력값을 넣어둔다
2. n == 1 인 경우 바로 최대값을 StringBuilder에 적재한다
3. n이 1이 아닌 경우 초기값으로 배열의 1번째에 값을 쌓는다
4. dp[0][i] 에 dp[1][i-1] 과 dp[1][i-2] 를 비교해 더 큰것을 추가한다
5. dp[1][i] 에 dp[0][i-1] 과 dp[0][i-2] 를 비교해 더 큰것을 추가한다
6. 연산 종료 후 dp[0][n-1] 과 dp[1][n-1] 중에 더 큰 것을 StringBuilder에 적재한다
7. 최종적으로 StringBuilder에 적재된 값을 출력한다
