## B 11568 - 민균이의 계략

**문제 링크 :** https://www.acmicpc.net/problem/11568  
**알고리즘 :** DP  
**언어 :** JAVA  

[ 코드 보기 ](../../src/dp/B11568.java)  

---

### 문제 요약

lis를 적극 활용하는 문제.  

---

### 핵심 아이디어

- dp (lis)
- 이분탐색을 통한 인덱스 확인

---

### 문제 접근 방식

1. 입력값과 lis를 저장할 배열을 각각 생성
2. lis의 사이즈를 외부에 두어 관리
3. 현재 lis의 마지막 값과 비교하여 증가상태라면 사이즈를 늘리고 마지막 인덱스에 값을 부여
4. 감소한다면 이분탐색을 통해 가장 최적인 위치를 찾아 해당 위치에 삽입 (사이즈는 그대로)
5. 최종적으로 size 값을 출력
